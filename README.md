# SuvidhaSethu
SuvidhaSetu is a smart civic grievance platform that enables citizens to report issues like potholes, garbage overflow, and water leakage with photos and GPS location. It supports complaint tracking, community voting, admin task assignment, and worker progress updates with proof of resolution, promoting transparency and cleaner cities.
